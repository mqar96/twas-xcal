## Qualifications used in the submission
- **Fixed-vector derivation:** it assumes a fixed retained SNP set and independent LD and GWAS samples. Panel-dependent SNP filtering and GWAS frequency estimation add practical approximations. Fixing panel-derived SDs during jackknife deletion does not establish conditional validity of the fallback.
- **Moment identity:** exact for an uncentered Gaussian sample covariance with known population standardization. Its use with estimated sample correlations of genotypes is approximate. Reported bias is an empirical result for the tested grid, not a universal guarantee.
- **Estimated parameters:** LOCO point estimates exclude the tested pseudo-chromosome. Script 08 averages SEs from the first five evaluated genomes with only pseudo-chromosome 0 excluded and reuses them across chromosomes/genomes. For these pilot genomes an SE used on another chromosome can depend on that chromosome's z-scores. The archived `conditional_ratio` fields are therefore approximate model-based Gaussian rates, not exact conditional calibration results for the entire experiment. The 0.98–1.05 extreme-tail range is restricted to nonzero infinitesimal settings. Approximately 1,062,000 evaluations per cell imply only 2.655 expected extreme-tail rejections at alpha 2.5e-6.
- **Parameter covariance:** the implemented df uses diagonal variance terms and omits a–c covariance and interactions with estimated LD moments. That omission has no universal conservative direction. Clipping the intercept/slope also limits a Gaussian delta approximation.
- **Real genotypes:** both reference half A and designated-truth half B are estimated. This design does not isolate which half causes predicted distortion. Non-European slope ratios compare full target/full European panels; the EUR control compares full/half European panels. These are predictions, not counted false positives from real phenotypes.
- **Biobank Japan:** median-based lambda near one and fewer discoveries do not establish null calibration or identify true genes. The regression SNP set differs from the LD-score-summed set, so their scale conventions should not be treated as interchangeable heritability estimates. Archived n_snps is matched pre-monomorphic-filter count, not full retained-weight coverage.
- **Genomic control:** the median is approximated from a 2,000-point grid; the second pass counts rejections exactly at that fitted lambda. Bootstrap intervals hold lambda fixed rather than refitting it.
- **Sparse effects and power:** Gaussian-reference variance calibration fails under the tested point-normal null, which redraws causal configurations. This does not rule out architecture-aware inference. Power calculations use known parameters and procedures with unequal error rates; they do not establish power superiority at matched error control.

## Maintenance fixes
The development wrapper measures retained polymorphic squared-weight coverage, reports the number of panel-monomorphic matched SNPs, and applies min_coverage to retained weights. Harmonization complements EAF on effect-allele reversal and preserves original_eaf; sqrt(2f(1-f)) is unchanged by that complementation. Nonfinite denominators and invalid one-block/noninteger jackknife requests are rejected. The direct panel-SD interface warns. The main null resume identity includes core.py; paper build source names/instructions are corrected. Regression tests cover these cases. This update adds no new calibration evidence.
